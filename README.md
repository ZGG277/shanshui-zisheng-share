# 山水自生 · 2D（分享版）

一张会生长的青绿山水画。洒下沙、水、岩、土、种子、木屑、油、火、雪与金粉，让流动与生长形成画作。

这是发布到小红书小工具的「山水自生」2D 版的分享源码（工程构建标识 `bottom-dock-exp.5-q1`）。纯前端、零依赖、零后端：打开 `index.html` 就能玩。

## 怎么玩

- **十种材料**：底部材料栏点选沙、水、岩、土、种、木、油、火、雪、金，在画布上拖动即可挥洒；
- **三种配色**：青绿、墨青、赭金，取自矿物颜料，切换配色不画面里的一粒沙；
- **寒暖拨杆**：拨向冷，云雨成雪、水面薄冰、阔叶落叶、松针托雪；再拨回暖，雪冰渐融、枝头再生叶；
- **起景**：青山、云雨、融雪三个一键开局的预设场景；
- **水循环闭合**：水 → 蒸汽 → 云 → 雨／雪 → 地表水 → 再蒸发，「每一滴都能再回来」；
- **树会生老病死**：种子落在湿润稳定的土上发芽，约七成阔叶、三成松；树会蒸腾、落叶、落种，也会被烧死、旱死；
- **淘金**：沙里藏着约 0.9% 的金沙，用水冲洗湿沙可以把金粉筛出来；
- **声音全合成**：雨声、火苗噼啪、落雪风铃、撒沙颗粒感都由 Web Audio 即时合成，随画面里真实的粒子活动量起伏；
- 画作自动保存在当前设备；普通浏览器中「分享到小红书 / 存到相册」会明确停用并提示（这两个能力由小红书容器注入，页面不会伪造成功）。

## 本地运行

无需构建，任选其一：

```sh
open index.html
# 或
python3 -m http.server 7164 --bind 127.0.0.1
```

## 技术要点

- 约 17 万格元胞自动机（随屏幕长宽比自适应），30Hz 固定步进；
- 17 种材质状态、1/4 分辨率粗粒度热场扩散、块级寒／水计数驱动相变；
- Canvas 2D 渲染：纸纹底、矿物色、云雾用浮力密度场渲染成有留白的水汽；
- 全部源码约 1600 行，无框架、无构建步骤。

生态与相变采用玩具规则，不是现实物理模型。
